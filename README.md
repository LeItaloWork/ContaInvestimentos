# 📌 Descrição do Projeto
Este é um sistema em Java para **gerenciamento de investimentos**, permitindo o controle de **usuários, empresas, contas de investimento, transações e ativos cripto**. Ele utiliza um banco de dados Oracle para armazenar os dados e possui menus interativos para facilitar a navegação.

---

## 🚀 Tecnologias Utilizadas
- **Java**  
- **JDBC** (para conexão com banco de dados)  
- **Banco de Dados Oracle**  

---

## 📦 Como Rodar o Projeto

1. **Clone o repositório**  
```sh
 git clone https://github.com/LeItaloWork/Ecogrid.git
```

2. **Abra o projeto no IntelliJ ou Eclipse**  

3. **Edite as credenciais do banco de dados**  
No arquivo `Main.java`, altere:  
```java
String url = "jdbc:oracle:thin:@oracle.fiap.com.br:1521:orcl";
String user = "SEU_USUARIO";
String password = "SUA_SENHA";
```

4. **Compile e execute o projeto**  
```sh
 javac Main.java
 java Main
```

---

## ✨ Funcionalidades

✅ **Gerenciamento de Usuários**  
- Criar, listar, atualizar e remover usuários  

✅ **Gerenciamento de Empresas**  
- Criar, listar, atualizar e remover empresas  

✅ **Gerenciamento de Contas de Investimento**  
- Criar, listar, atualizar e remover contas de investimento  

✅ **Gerenciamento de Transações**  
- Registrar e visualizar transações  

✅ **Gerenciamento de Ativos Cripto**  
- Criar, listar e remover ativos cripto  

✅ **Sistema de Participação em Investimentos**  
- Gerenciar participações em investimentos vinculadas a contas e ativos cripto
